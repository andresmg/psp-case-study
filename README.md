# PSP — Patient support platform

Full-stack web platform for a **Grupo Leti** patient support program, with three role-based portals: **Admin**, **Patient** and **Delegate**.

> The source code is private (client project). This repository is a case study. Screenshots coming soon.

## My role

Full-stack development (front-end and API) and UI/UX improvements.

## Highlights

- Role-based dashboards with charts, date-range filtering and Excel export
- Rich-text content editing and notifications
- Security-first API: argon2 password hashing, encrypted user data, hardened sessions and HTTP headers, and an automated security test suite covering authorization, registration, account flows and response filtering

## Stack

React 19 · React Router · Recharts · Bootstrap · Node 22 · Express · MongoDB / Mongoose · Firebase Hosting
